## ccfolia ログ整形ツール

ココフォリアのログを読みやすく整形して表示・保存する、ブラウザだけで動作するツールです。

**主な機能**
- 従来ログと公式HTMLログ（ZIP / 展開済みHTML）を自動判別して読み込み
- 公式ログの「すべて」タブを時系列の基準にし、タブ横断で統合表示
- 「すべて」表示ではメイン以外のタブを帯・背景・タブ名で明確に区別
- 公式ログに埋め込まれたアイコンを引き継ぎ、単一HTMLへ重複なく保存
- GM/KPとPCの役割をパネルから切り替え、文章の見た目を分離
- キャラクターアイコン・カラーの上書き、発言ごとのスチル画像挿入
- キャラ絞り込み、タブ切り替え、クリティカル／ファンブル回数の確認
- 文字サイズ（小・中・大）とライト／ダークテーマの切り替え
- CSS・画像を埋め込んだ単一HTML、またはテキストとして保存
